- app.js y styles.css: efecto de hojas y diseño.

Las fotografías 01-10 siguen el orden de los otros diez archivos que enviaste.

PARA PUBLICAR EN UN REPOSITORIO NUEVO
1. Entra en github.com con babykidsstudioec y crea un repositorio PUBLIC llamado: mayerli-tobar
2. Desde tu computadora abre PowerShell en el Escritorio.
3. Ejecuta: git clone https://github.com/babykidsstudioec/mayerli-tobar.git
4. Descomprime este ZIP y copia TODO su contenido (incluyendo la carpeta assets) dentro de la carpeta mayerli-tobar creada por Git.
5. Abre esa carpeta en Visual Studio Code y en la terminal ejecuta:
   git add .
   git commit -m "Crear album Mayerli Tobar"
   git branch -M main
   git push -u origin main
6. En GitHub > repositorio mayerli-tobar > Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
7. El enlace será: https://babykidsstudioec.github.io/mayerli-tobar/

NO se modifica el repositorio anterior de Navidad.
